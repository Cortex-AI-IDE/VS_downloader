Which file is right for my phone?

The app contains a Python runtime and FFmpeg, so it is built once per processor type. Your phone only uses one of them, which is why a single file is not enough and why each file is smaller than one that contains all of them.

FileSizeUse it for
app-arm64-v8a.apk 59 MB Almost every phone released since 2017
app-armeabi-v7a.apk 52 MB Older 32-bit phones
app-x86_64.apk 62 MB Android emulators only
app-universal.apk 151 MB Fallback if you are not sure

To confirm your processor type, connect the phone to a computer and run adb shell getprop ro.product.cpu.abi. A result containing arm64 means the first file is correct.

How to install on your phone

Android blocks apps from outside the Play Store until you allow them, so the first install asks one extra question. It takes about two minutes.

  1. Download the APK Tap the download button above. The file saves to your phone storage and appears in your notifications or in the Downloads folder. Keep the page open if the browser shows a progress bar.
  2. Allow installs from your browser When Android says your phone is not allowed to install unknown apps, tap Settings in that prompt and turn the switch on for Chrome, or whichever browser you used. The table below lists the menu path for common brands.
  3. Open the file and tap Install Open the download from the notification or from your Files app. If Google Play Protect says the app is unsafe because it is from an unknown developer, tap More details, then Install anyway. That message appears because the build is not signed by the Play Store, not because the file is damaged.
  4. Launch the app The first launch unpacks the download engine, which takes a few seconds. Then paste any supported video link and tap Download.

If something goes wrong

Find the message you saw in the list below. Each one has a single cause and a short fix.

The download does not start at all

This is the most common failure, and it is almost always the browser rather than the file. If you tapped the link inside Instagram, Facebook, Messenger, WhatsApp or Telegram, the page opened in that app's built in browser, which cannot save an APK.

  1. Open the link in Chrome, not in the app you found it in.
  2. In the app, tap the three dot menu and choose Open in browser if it is offered.
  3. The arm64 file is stored on this site, so it never passes through GitHub. If an older link showed 504 Gateway Time-out, go back to the download button at the top of this page instead.
  4. If it still fails, switch between Wi-Fi and mobile data, then retry.
  5. The releases page holds the other architectures. Use it only if the arm64 file is wrong for your phone.
App not installed
An older copy of Video Saver signed with a different key is already on the phone, or the download was cut short. Uninstall the old Video Saver first, then install the new file. If nothing was installed before, check the file size in your Downloads folder against the size shown on this page and download again if it is smaller.
There was a problem parsing the package
The file is incomplete or the browser renamed it. A partial download is the usual cause. Delete it, then download again on a stable connection. If the file name ends in .apk.zip or .bin, rename it so it ends in .apk.
Your phone is not allowed to install unknown apps
Use the allow switch described in the section above, then tap the downloaded file again. Turning the switch on does not install anything by itself, it only permits the browser to ask.
Play Protect says the app is unsafe
Tap More details, then Install anyway. The warning refers to the signing key, since a community build is signed with a debug key rather than a Play Store key. The source code is public if you want to inspect what the app does.
Installation blocked because the file is harmful
Chrome sometimes holds back APK downloads. Open the download entry in Chrome, tap Download anyway when offered, or use your Files app to open the file directly.
The app opens but downloads fail
That is a separate problem from installation. See the troubleshooting page, which covers engine unpacking errors and unsupported links.

Verify the download

Every release publishes a checksum file, so you can confirm the APK arrived intact. On a computer, compute the hash and compare it with the matching line in SHA256SUMS.txt.

On macOS use shasum -a 256 app-arm64-v8a.apk. On Windows PowerShell use Get-FileHash app-arm64-v8a.apk -Algorithm SHA256.

Common questions

Is the APK safe?

The file is built by the project's own automated build from the public source code under GPL-3.0. The install warning exists because the app is distributed outside the Play Store, not because of anything in the file. You can rebuild it yourself with the instructions in the repository.

Why is it not on Google Play?

Play policy does not allow apps that download media from other platforms. Direct APK distribution is the alternative, and an F-Droid listing is planned.

Will installing this version keep my existing videos?

Yes. Videos are saved in the public Download/VideoSaver folder, outside the app, so an upgrade or a reinstall does not remove them.

Which Android versions work?

Android 7.0 and newer. The app targets Android 15 and follows current storage rules, so it asks for no broad file permission.
